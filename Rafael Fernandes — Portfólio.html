Robô de automação para verificação de equipamentos SCADA/e-terra

Em desenvolvimento

Problema: a verificação de equipamentos em ambiente SCADA envolve muitas consultas manuais e repetitivas.

Solução: scripts PowerShell leem listas de equipamentos em CSV e automatizam a interação com a interface do e-terra/WebFG SCADA, pesquisando cada equipamento pelo padrão de consulta DISP. O robô captura telas e analisa indicadores visuais (caracteres “X”) para apontar possíveis divergências, e organiza os resultados no Excel para a conferência e os relatórios.

Próximos passos: integração com fontes de dados via OLE DB (somente leitura) e avaliação de OCR.

  • PowerShell 5.1
  • CSV
  • Excel
  • Automação de interface
  • Windows Server / RDP

Por se tratar de um ambiente corporativo, o código e as imagens reais não são públicos. O repositório mostrará uma versão genérica e anonimizada da abordagem.
